### Notes

- **M04.05 done (2026-11-14 session).** Persistent undo archives
  (`docs/notes/m04-05-undo-archive.md`): versioned little-endian transaction
  payloads in the shared checksummed journal container, strict base-content
  hashes, dense IDs/parents, metadata and selection preservation, nonempty
  revision-0 snapshots, full branch/root reconstruction through `doc_apply`, and
  verified-prefix replay. Six new tests cover exact and randomized branch round
  trips, torn/corrupt tails, malformed payloads, identity conflicts, and limits.
  Validated 27/27 txn tests leak-free ×20 (+ single-threaded), full suite 228
  tests clean, debug/release builds, Xvfb smoke, and Windows cross-check.
  Windows runtime, active branch-position persistence, reopened-file identity,
  product integration, and interactive retention/navigation remain open.

- **M04.04 done (2026-11-14 session).** OS-backed session locks
  (`docs/notes/m04-04-session-lock.md`): nonblocking Linux flock and Windows
  LockFileEx adapters, persistent lock files without inode-replacement races,
  fixed checksummed process-instance records, active/stale/new results, heartbeat
  metadata, and idempotent release. PID or heartbeat age never authorizes
  takeover. Four new tests cover real contention, stale reuse, corruption,
  oversized records, invalid input, and cleanup. Validated 33/33 journal tests
  leak-free ×20 (+ single-threaded), full suite 222 tests clean, debug/release
  builds, Xvfb smoke, and Windows cross-check. Windows lock runtime, network
  filesystem semantics, product startup integration, and process-kill proof are
  not claimed.

- **M04.03 done (2026-11-14 session).** Crash recovery discovery
  (`docs/notes/m04-03-discovery.md`): bounded streaming scans of canonical
  generation files, strict embedded identity/generation matching, highest-valid
  fallback, torn-tail prefixes, checkpoint-only and initial journal-only recovery,
  and non-destructive incomplete-generation issues. Six new tests cover newest
  selection, corrupt/mismatched fallback, orphan and checkpoint-only cases,
  limits, evidence preservation, and Linux symlink rejection. Validated 29/29
  journal tests leak-free ×20 (+ single-threaded), full suite 218 tests clean,
  debug/release builds, Xvfb smoke, and Windows cross-check. Windows directory
  runtime, multi-buffer session recursion, locks, and crash/power-loss proof stay
  explicitly open.

- **M04.02 done (2026-11-14 session).** Checkpointing and generation rotation
  (`docs/notes/m04-02-checkpoint-rotation.md`): all-or-nothing checksummed full
  snapshots retain original disk identity, journal format 2 adds generation IDs,
  and `recover_generation` pairs snapshots with verified tail prefixes. Caller-
  driven time/size/count triggers and ordered publication preserve the old writer
  on pre-publication failure and explicitly report post-publication cleanup
  errors. Nine new tests cover reconstruction, corruption/limits, successful and
  interrupted rotation, close/sync/remove faults, and policy triggers. Validated
  23/23 journal tests leak-free ×20 (+ single-threaded), full suite 212 tests
  clean, debug/release builds, Xvfb smoke, and Windows cross-check. Discovery,
  Windows runtime, directory sync, and actual crash/power-loss proof remain open.

- **M04.01 done (2026-11-14 session).** Versioned journal primitive
  (`docs/notes/m04-01-journal.md`): explicit little-endian header/record
  encoding, SHA-256 base identity, CRC32 integrity, contiguous sequences and
  timestamps, exclusive append/sync writing, bounded valid-prefix replay, and
  strict file/content identity validation. Fourteen isolated tests cover all
  torn-tail offsets, corruption/version/sequence/limits, random round trips,
  short writes, and poisoned writers. Validated 14/14 leak-free ×20 (+
  single-threaded), full suite 203 tests clean, debug/release builds, Xvfb
  smoke, and Windows cross-check. No Windows runtime, checkpoint/rotation,
  discovery, transaction application, or power-loss proof is claimed.
