### Notes

- **M04.02 done (2026-11-14 session).** Checkpointing and generation rotation
  (`docs/notes/m04-02-checkpoint-rotation.md`): all-or-nothing checksummed full
  snapshots retain original disk identity, journal format 2 adds generation IDs,
  and `recover_generation` pairs snapshots with verified tail prefixes. Caller-
  driven time/size/count triggers and ordered publication preserve the old writer
  on pre-publication failure and explicitly report post-publication cleanup
  errors. Nine new tests cover reconstruction, corruption/limits, successful and
  interrupted rotation, close/sync/remove faults, and policy triggers. Validated
  23/23 journal tests leak-free ×20 (+ single-threaded), full suite 212 tests
  clean, debug/release builds, Xvfb smoke, and Windows cross-check. Discovery,
  Windows runtime, directory sync, and actual crash/power-loss proof remain open.

- **M04.01 done (2026-11-14 session).** Versioned journal primitive
  (`docs/notes/m04-01-journal.md`): explicit little-endian header/record
  encoding, SHA-256 base identity, CRC32 integrity, contiguous sequences and
  timestamps, exclusive append/sync writing, bounded valid-prefix replay, and
  strict file/content identity validation. Fourteen isolated tests cover all
  torn-tail offsets, corruption/version/sequence/limits, random round trips,
  short writes, and poisoned writers. Validated 14/14 leak-free ×20 (+
  single-threaded), full suite 203 tests clean, debug/release builds, Xvfb
  smoke, and Windows cross-check. No Windows runtime, checkpoint/rotation,
  discovery, transaction application, or power-loss proof is claimed.
