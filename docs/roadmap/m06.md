### Notes

- **M06.14 done (2026-11-16 session).** Ctrl+plus/minus/zero, keypad equivalents,
  and exact Ctrl+wheel adjust runtime text size from 4–72 pt without editing the
  buffer (`docs/notes/m06-14-text-zoom.md`). Layout, shaping, hit-testing, and the
  resettable glyph atlas share the effective size. Eight X11 zoom rebuilds retained
  two atlas pages and preserved exact selection/caret bytes. All 321 unit tests,
  typing, autopair, and IME suites passed; Windows-target core checks passed.
- **M06.13 done (2026-11-16 session).** Configurable autopair handles brackets,
  braces, parentheses, and quotes; wraps selections; skips adjacent closers;
  reuses unmatched bracket closers across up to 1000 lines; and deletes empty
  pairs (`docs/notes/m06-13-autopair.md`). `autopair` defaults to true and has
  real X11 enabled/disabled product coverage. All 319 unit tests, typing and IME
  regression suites, and Windows-target core checks passed. The full Windows
  build remains blocked by the existing `-ignore-vs-search` flag.
- **M06.12 done (2026-11-16 session).** Enter copies the first selected line's
  exact leading spaces/tabs in the same typing transaction as the newline;
  reverse/multiline selection replacement, caret placement, and undo/redo are
  covered (`docs/notes/m06-12-newline-indentation.md`). All 309 unit tests and
  real X11 product byte/undo checks passed. The Windows cross-build remains
  blocked before source compilation by the existing `-ignore-vs-search` flag.
- **M06-Detour-2 done (2026-11-16 session).** Ctrl+X waits for a successful
  native clipboard-write result before applying one revision/anchor-validated Cut
  transaction; Ctrl+Shift+C/V alias copy/paste (`docs/notes/m06-detour-2-cut.md`).
  All 307 unit tests, native X11 clipboard interoperability, and real X11 product
  cut/alias/undo checks passed. The Windows cross-build stopped before source
  compilation because the installed compiler rejects `-ignore-vs-search`.
- **M06-Detour-1 done (2026-11-16 session).** Split ICU/HarfBuzz graphemes now
  retain valid layout, and bounded on-demand fontconfig fallback renders complex
  scripts and symbols (`docs/notes/m06-detour-1-special-characters.md`). All 38
  native text tests, 302 unit tests, Unicode/emoji/typing/ligature X11 suites,
  and the Windows cross-build passed. Non-Linux rendering remains unvalidated.
- **M06.11 done (2026-11-16 session).** Ctrl+C publishes the selected rope range
  through the native clipboard, and Ctrl+V uses revision/selection-validated
  delayed paste (`docs/notes/m06-11-copy-paste.md`). Real X11 product/external-
  application checks, native Linux and Windows/Wine clipboard suites, all 300
  unit tests, all 28 native text tests, both product builds, and lifecycle smokes
  passed. Windows product key events and Wayland remain unvalidated.
- **Modified-Backspace detour done (2026-11-16 session).** Ctrl and Shift preserve
  ordinary grapheme Backspace; Alt+Backspace deletes to the previous word-motion
  boundary as one undoable transaction (`docs/notes/modified-backspace.md`).
  Resolver/editing tests, all 301 unit tests, real X11 product checks, and the
  Windows cross-build passed. This did not change the active M05.10 task.
