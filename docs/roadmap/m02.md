- **M02.08 done (2026-11-13 session) — M02 complete.** Randomized
  differentials and bounded benchmarks (`docs/m02-08-benchmarks.md`):
  deterministic no-whole-buffer-copy guards (counting allocator,
  node-count/chunk-store/height deltas on 2 MiB buffers — a small

  differential (content + tree structure + an independent metric

  `make.odin bench` target. Validated 28/28 rope + 21/21 txn tests
  leak-free ×11 (no flake), 115-test full suite clean, debug/release

- **M02.07 done (2026-11-13 session).** Branching in-memory undo
  (`docs/m02-07-undo.md`): the M02.05 log became the SPECS.md §8.4
  undo tree — `Log_Entry` nodes gain parent/child ids, a `core:time`
  timestamp, and before/after `Selection` state; `Doc` gains
  `current` and a global `next_revision` counter (branching breaks
  `after = base + 1`; revisions stay unique, §4.3 stale rejection
  untouched). `doc_apply` links nodes all-or-nothing; `doc_check`
  validates the tree structure (parent/child symmetry, base/before
  vs parent, current state vs tree root, counters). New `undo.odin`:
  `Selection`, `doc_undo`/`doc_redo` (pointer-only jumps),
  `doc_undoable`/`doc_redoable`, `.NotFound` for the boundaries, and
  `grouping_key` runs as one undo unit in both directions; redo
  follows the most recent child. `anchor_transform` replays the
  current path; abandoned-branch anchors are `.Conflict`. 7 new
  tests (18 in the package) incl. a 600-step apply/undo/redo
  differential with random groups/selections and an anchor pool vs
  an independent reference tree (caught two test-side bugs: a
  zero-padded reference clone, an all-colliding empty-op no-op gap).
  Validated 18/18 leak-free ×10 (+ single-threaded), full suite 108
  tests clean, debug/release builds, Xvfb release smoke, `-no-crt`
  Windows cross-build + Wine 11 consumer (branching, grouping,
  anchors, exit 0). No product consumer yet.

- **M02.05 done (2026-11-13 session).** Transactions and revision

- **M02.04 done (2026-11-13 session).** Coordinate conversion

- **M02.03 done (2026-11-12 session).** Balancing and persistent root
  updates (`docs/m02-03-tree.md`): `tree.odin` in `src/core/rope` — a
  persistent copy-on-write B-tree (`Node` kind-tagged leaf/internal,
  single intrusive-link pool, `Tree` root+revision). Inserts splice
  interned pieces and cascade leaf repacks + balanced internal splits;
  deletes split boundary pieces, drop emptied leaves, merge under-full
  internal children left-first, and collapse single-child roots;
  snapshots stay byte-identical via `tree_read_root(_all)`;
  `tree_check` validates bounds/depth/pieces/metrics. 8 new tree tests
  (19 in the package) incl. a 500-step differential (content + metrics
  vs `metrics_of` and the independent oracle + invariants + revision +
  span iteration + snapshot probes) that caught three real bugs:
  fixed-array slices including zeroed entries, a sibling-merge
  ordering scramble (also the cause of a segfault), and a missing
  `combine` leading-run carry. Validated 19/19 leak-free ×10, full
  suite 84 tests clean, debug/release builds, Xvfb release smoke,
  `-no-crt` Windows cross-build + Wine 11 consumer (snapshot
  persistence, exit 0). No product consumer yet (M02.05).
