### Notes

- **M05.01 done (2026-11-14 session).** Narrow Linux bindings for FreeType
  2.15.0, HarfBuzz 12.3.2, and ICU4C 78.3/Unicode 17.0, plus shaderc/glslc
  2026.3, are pinned with licenses and exact build/runtime checks
  (`docs/notes/m05-01-text-dependencies.md`). Four native integration tests,
  all 242 existing unit tests, the debug build, and an Xvfb smoke test passed.
  Windows/macOS, renamed-symbol ICU, valid-font rasterization, and real-script
  visual shaping are explicitly not claimed by this binding task.
- **M05.02 done (2026-11-15 session).** Fontconfig 2.18.3 discovery, ordered
  named/generic family matching, explicit font paths, and independent body/tag/
  console FreeType faces are implemented (`docs/notes/m05-02-font-discovery.md`).
  Config schema 2 supports per-role family stacks and a global path override.
  Eight native tests, all 245 unit tests, default and explicit-path Xvfb product
  smokes, and the Windows cross-build passed. Non-Linux discovery remains
  explicitly unsupported; Windows runtime discovery was not tested.
- **M05.03 done (2026-11-15 session).** Bounded CPU glyph atlases now have full
  identity/variation/glyph/size/mode keys, dirty tracking, page-LRU eviction,
  and explicit cleanup (`docs/notes/m05-03-glyph-cache.md`). FreeType coverage
  and Sokol R8 pages are integrated with product startup/shutdown. Five cache
  unit tests, nine native tests, all 250 unit tests, Linux GPU smoke, and the
  Windows cross-build passed. No visual text output or non-Linux GPU runtime is
  claimed yet.
