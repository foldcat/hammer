### Notes

- **M05.01 done (2026-11-14 session).** Narrow Linux bindings for FreeType
  2.15.0, HarfBuzz 12.3.2, and ICU4C 78.3/Unicode 17.0, plus shaderc/glslc
  2026.3, are pinned with licenses and exact build/runtime checks
  (`docs/notes/m05-01-text-dependencies.md`). Four native integration tests,
  all 242 existing unit tests, the debug build, and an Xvfb smoke test passed.
  Windows/macOS, renamed-symbol ICU, valid-font rasterization, and real-script
  visual shaping are explicitly not claimed by this binding task.
- **M05.02 done (2026-11-15 session).** Fontconfig 2.18.3 discovery, ordered
  named/generic family matching, explicit font paths, and independent body/tag/
  console FreeType faces are implemented (`docs/notes/m05-02-font-discovery.md`).
  Config schema 2 supports per-role family stacks and a global path override.
  Eight native tests, all 245 unit tests, default and explicit-path Xvfb product
  smokes, and the Windows cross-build passed. Non-Linux discovery remains
  explicitly unsupported; Windows runtime discovery was not tested.
- **M05.03 done (2026-11-15 session).** Bounded CPU glyph atlases now have full
  identity/variation/glyph/size/mode keys, dirty tracking, page-LRU eviction,
  and explicit cleanup (`docs/notes/m05-03-glyph-cache.md`). FreeType coverage
  and Sokol R8 pages are integrated with product startup/shutdown. Five cache
  unit tests, nine native tests, all 250 unit tests, Linux GPU smoke, and the
  Windows cross-build passed. No visual text output or non-Linux GPU runtime is
  claimed yet.
- **M05.04 done (2026-11-15 session).** `src/text/shaping` now maps valid UTF-8
  through ICU grapheme/bidi processing and HarfBuzz into owned visual-order
  positioned runs, with cluster-boundary font fallback, source-byte clusters,
  diagnostics, and cache-key generation (`docs/notes/m05-04-shaping.md`).
  Combining, Hebrew fallback/bidi, Arabic contextual forms, and failure cleanup
  are covered by fixture-based native tests. Fourteen native tests and all 250
  unit tests passed; product visual text and non-Linux shaping remain unclaimed.
- **M05.05 done (2026-11-15 session).** Shaped runs now own visual-order
  grapheme layouts, including ligature advance subdivision. Allocation-free
  caret hit/position mapping preserves leading/trailing bidi edges, and owned
  selection spans coalesce adjacent graphemes while retaining disjoint bidi
  geometry (`docs/notes/m05-05-hit-testing.md`). Twenty native tests, all 250
  unit tests, Linux GPU smoke, and the Windows product cross-build passed.
  Product mouse/drawing integration, native single-glyph ligature coverage, and
  non-Linux hit-testing runtime remain unclaimed.
- **M05.06 done (2026-11-15 session).** Validated scale/font generations now
  drive layout and glyph invalidation, with bounded X11 RandR monitor tracking
  and allocation-reusing atlas resets (`docs/notes/m05-06-dpi-invalidation.md`).
  Five DPI tests, six glyph-cache tests, all 256 unit tests, twenty native text
  tests, Linux scale-sequence/render smokes, and the Windows cross-build passed.
  Real dual-monitor movement, non-Linux runtime DPI, and product shaped-line
  cache/text drawing remain unclaimed.
- **M05.07 done (2026-11-15 session).** Streaming visible-range shaping now
  bounds each call, uses bounded grapheme lookahead, preserves absolute source
  offsets, accumulates width incrementally, and marks independent-chunk bidi/
  joining fallback explicitly (`docs/notes/m05-07-huge-lines.md`). Quadratic
  fallback scans were replaced with binary searches and diagnostics capped at
  64. Bounded 10 MiB reads and complete 2 MiB processing pass with all 25 native
  tests, all 256 unit tests, Linux build/smoke, and the Windows cross-build.
  Product drawing and non-Linux streaming shaping remain unclaimed.
- **M05.08 done (2026-11-15 session).** Deterministic CPU visual fixtures now
  composite shaped atlas pixels for combining/CJK, emoji, Hebrew selection,
  Arabic, bidi controls, and segmented fallback at all four required DPI scales
  (`docs/notes/m05-08-visual-fixtures.md`). Bundled CJK/monochrome-emoji subsets
  include OFL notices. Four byte-exact goldens passed with all 26 native tests,
  all 256 unit tests, Linux build/smoke, and the Windows cross-build. Product-
  window text drawing, non-Linux rendering, and real monitor handoff remain
  unvalidated.
- **M05.09–M05.10 reopened (2026-11-16 session).** Native single-glyph ligature
  coverage and color-emoji/full-emoji-sequence rendering were recorded as
  unclaimed in M05.05/M05.08 and are now scheduled as explicit follow-ups.
  Text zoom is tracked separately as M06.14 (modern shortcut).
- **M05.09 done (2026-11-16 session).** Optional standard/contextual ligatures now
  honor configuration, including the `calt` programming-ligature path
  (`docs/notes/m05-09-ligatures.md`). Bundled Noto `fi` and JetBrains `==`
  fixtures validate native shaping, caret/selection geometry, and rasterization.
  All 30 native text tests, all 300 unit tests, real enabled/disabled X11 product
  rendering, existing typing/clipboard checks, and the Windows cross-build passed.
  Non-Linux shaping/rendering and discretionary/historical fixture coverage remain
  unvalidated.
- **M05.10 done (2026-11-16 session).** Emoji-aware cluster fallback, fixed-strike
  color rasterization, separate Alpha/RGBA atlases, and premultiplied product
  rendering are implemented (`docs/notes/m05-10-color-emoji.md`). ZWJ, skin-tone,
  family, VS16, flag, and keycap sequences pass native and real X11 product tests,
  including grapheme deletion and undo. All 33 native text tests, all 302 unit
  tests, existing ligature/typing checks, and the Windows cross-build passed.
  Non-Linux rendering, COLRv1/SVG, and tag-sequence fixtures remain unvalidated.
