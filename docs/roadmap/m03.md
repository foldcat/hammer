### Notes

- **M03.06 done (2026-11-14 session).** Disk-change conflict detection
  (`docs/notes/m03-06-filestate.md`): `src/core/filestate` polls handle-based
  captures into Unchanged/Modified/Replaced/Missing, offers reload for clean
  changes, and exposes deliberate dirty-buffer conflict choices without
  mutating editor state. Identity-less observations are explicit; normal save
  rejects unverified `.Unchanged` checkpoints unless size/mtime-only checking
  is deliberately enabled. Six new filestate tests plus a filesave regression
  cover real edits/replacement/deletion and degraded identity. Validated 6/6
  leak-free ×10 (+ single-threaded), full suite 183 tests clean, debug/release
  builds, Xvfb smoke, and a Windows `-no-crt` consumer under Wine. No automatic
  reload, OS watcher, or UI integration is claimed; M03.07 owns fault injection.
- **M03.05 done (2026-11-14 session).** Temporary-write/replace save
  (`docs/notes/m03-05-filesave.md`): `src/core/filesave` streams immutable rope
  roots to same-directory temporary files, preserves UTF-8 BOM/newline bytes and
  permissions, syncs before publication, and returns a revisioned fresh
  checkpoint without mutating dirty state. Explicit new-file/unchanged/overwrite
  policies, atomic no-clobber Save As, bounded symlink following, read-only and
  hard-link-break safeguards, and post-publication `replaced` reporting. 13 new
  tests cover open/save/reopen, stale conflicts, permissions, links, empty files,
  and failures. Validated 13/13 leak-free ×10 (+ single-threaded), full suite 176
  tests clean, debug/release builds, Xvfb smoke, and Windows `-no-crt` consumer
  under Wine. Directory sync, ownership/ACL preservation, and injected I/O faults
  are explicitly deferred/limited; M03.06 owns user-facing conflict detection.
- **M03.04 done (2026-11-14 session).** Explicit unsupported/invalid encoding
  behavior (`docs/notes/m03-04-encoding-behavior.md`): owned valid-UTF-8
  `Display` projections preserve literal text and escape invalid/unsupported
  bytes as `\xNN`, with coalesced raw/display `Offset_Map` spans and strict
  escape-interior rejection. Invalid UTF-8 stays read-only with plain-text
  parser fallback; unsupported UTF-16/32 stays read-only with parsing disabled.
  `convert_to_utf8` returns independent owned UTF-8, handles all Unicode BOMs
  and surrogate pairs directly from chunks, and requires `allow_lossy` before
  replacing malformed units with U+FFFD. 11 new tests include offset-boundary
  round-trips, 1000 random inputs, allocation failure, and real loader/display/
  conversion. Validated 21/21 leak-free ×10 (+ single-threaded), full suite 163
  tests clean, debug/release builds, Xvfb release smoke, and a `-no-crt` Windows
  consumer under Wine. No product UI consumer yet; saving is M03.05.
- **M03.03 done (2026-11-14 session).** UTF-8/BOM/newline policy
  (`docs/notes/m03-03-filecodec.md`): allocation-free, zero-copy
  `src/core/filecodec` over `Loaded` chunks. Byte-exact raw and BOM-excluding
  content streams, strict chunk-safe UTF-8 validation with first-error raw
  offsets, read-only invalid/unsupported states, UTF-16/32 BOM recognition,
  and LF/CRLF/lone-CR/mixed newline metadata without normalization. 10 new
  tests (`tests/unit/filecodec`) include standard-library differentials and a
  real loader round-trip. Validated 10/10 leak-free ×10 (+ single-threaded),
  full suite 152 tests clean, debug/release builds, Xvfb release smoke, and a
  `-no-crt` Windows consumer under Wine 11. No product consumer yet; escaped
  rendering/offset maps/conversion are M03.04, save encoding is M03.05.
- **M03.02 done (2026-11-13 session).** Background chunked loading
  (`docs/notes/m03-02-fileload.md`): the read/capture adapter feeding
  `src/core/fileid` from real files and loading content chunked into
  the M02 chunk store on a worker, with the `File_ID`/`File_Stamp`
  captured at load time (SPECS.md §6.4, §7.5, §11.1 step 2, §4.2–§4.4).
  New `src/core/fileload`: `Capture` + `capture_file` (handle-based
  fstat — Unix statx st_dev/st_ino, Windows
  `GetFileInformationByHandle`; `.None` on the inode-0/file-index-0
  conventions; the mtime split floors negative times; negative size
  `.Invalid_Input`), `load_file` (open → capture → chunked reads
  interned via `chunk.intern` → re-fstat the same handle and require
  `stamp_equal`, else `.Conflict` with the partial load discarded —
  all-or-nothing; regular files only; O_NONBLOCK open on Linux so a
  FIFO cannot block; a `cancel` flag aborts between chunks), and
  `Loader` (one worker thread, fixed-capacity 4/4 bounded queues, a
  thread-safe growing arena owning every request copy/result/store,
  sticky cancel/resume, close-drains, destroy joins+frees without
  deadlocking against backpressure; results echo the §4.3 request_id
  + worker tid). 19 new tests (`tests/unit/fileload`) incl. capture
  vs an independently built `os.stat` stamp, `.None` conventions,
  mtime-split boundaries, chunked round-trips, repeated-chunk
  interning, empty files, error paths, upfront cancel, two
  concurrent-writer property tests (atomic temp+rename flips must
  yield one complete state; in-place truncate+write must yield a
  complete state or the legitimate momentary empty snapshot, else
  `.Conflict`), and loader tests (backgroundness, id echo + FIFO,
  cancel/resume, close-drains, mid-load cancel on a 64 MiB fixture,
  destroy discarding, destroy of a never-started loader). Validated
  19/19 leak-free ×20 (+ single-threaded), full suite 142 tests
  clean, debug/release builds, Xvfb release smoke, `-no-crt` Windows
  cross-build + Wine 11 consumer (capture, `.None` conventions,
  validation error path, chunked load round-trip with stamp match,
  the worker loader — exit 0). No product consumer yet (M06/M07 wire
  buffer open; M03.06 reuses `capture_file` for conflict detection).
  Deferred to the M03.06 slice: canonical path resolution and volume
  case-sensitivity probing.
- **M03.01 done (2026-11-13 session).** Canonical file identity
  (`docs/notes/m03-01-fileid.md`): backend-free `src/core/fileid` — `File_ID`
  (kind + hi/lo: Unix st_dev/st_ino, Windows zero-extended volume
  serial / 64-bit file index; `.None` as one canonical value: inode 0
  and file index 0 map to it, hi/lo ignored in every comparison, never
  a dedup key), `id_equal` + total-order `id_cmp` (cmp == 0 iff
  equal), version-validated `File_Stamp` (id + size + mtime,
  `make_stamp` validates only nsec — size/mtime pass through
  unconstrained), `stamp_status` (Unchanged/Changed/Replaced:
  identity difference → Replaced incl. cross-kind; either id `.None`
  → size+mtime best effort, never Replaced), `stamp_equal`, and the
  §6.4 `Case_Sensitivity`/`Symlink_Policy` tracked attributes. No file
  I/O: the stat/path capture adapters land with M03.02/M03.06. 8 new
  tests (`tests/unit/fileid`) incl. two seeded differentials (250-id
  order vs an independent array-key reference with antisymmetry +
  cmp/equal agreement + transitivity; 1200-draw status vs an
  independently structured reference policy with reflexivity +
  symmetry + all-class coverage). Validated 8/8 leak-free ×10
  (+ single-threaded), full suite 123 tests clean, debug/release
  builds, Xvfb release smoke, `-no-crt` Windows cross-build + Wine 11
  consumer (constructors, none mapping, validation error path, all
  three status classes, exit 0). No product consumer yet (M03.02).
